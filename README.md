# ProjectName

A naive implementation of an http web server written on top of node's ```net``` module.

## Features
- HTTP/HTTPS support
- Easy configuration
- Fast and minimal

## Installation
```bash
```
git clone https://github.com/ZhengJiawen44/HttpWebServer.git
```
```

npm install
npm run start # to run the minimal example
