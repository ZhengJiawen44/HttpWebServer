HttpWebServer

A naive implementation of an HTTP web server using Node’s net module.

Features

  • HTTP/HTTPS support
  • Easy configuration
  • Fast and minimal

Installation

git clone https://github.com/ZhengJiawen44/HttpWebServer.git
cd HttpWebServer
npm install
npm run start # to run the minimal example

1. Class: Server

Responsible for binding TCP and handling request/response lifecycle.

Server(requestListener, options)

options {maxQuota?: number, timeout?: number}

import Server from "./HttpServer.ts";
import Response from "./response.ts";

const options = { timeout: 5000, maxQuota: 999 };
const server = new Server(
  async (req) => {
    return new Response(JSON.stringify(body), {
      status: 200,
      headers: { "Content-Length": "11" }
    });
  },
  options
);

Server.listen(port, host, onServerStart)

const port = process.env.port;
const host = process.env.host;

server.listen(port, host, () => {
  console.log(`server started on http://${host}:${port}`);
});
